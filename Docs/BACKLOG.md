# Бэклог Mad Machines

Открытые задачи по приоритету. К сетевому срезу переходить после проверки и настройки локального управления.

## P0 · Проверить локальную альфу

- [ ] Пройти [ручную проверку](CURRENT_STATE.md#проверка) в Unity. Зафиксировать результаты по каждому испытанию, читаемость HUD и сохранение рекордов.
- [ ] По итогам заездов настроить сцепление, центр масс, скорость наведения и силы отдачи. Повторить маршруты и проверить баланс результатов.

## P1 · Доработать полигон

- [ ] Восстанавливать положение, ориентацию и скорости подвижных препятствий при повторе попытки.
- [ ] Добавить базовый звук движения, выстрелов, столкновений и взрывов. Улучшить пыль, следы шин и визуальную обратную связь попаданий.
- [ ] Переиспользовать снаряды и кратковременные эффекты через пулы. Проверить очистку состояния при повторном запуске.
- [ ] Отделить настроенную машину от сцены: префаб T100, описание машины и запуск сессии с явным связыванием подсистем. Затем проверить вторую машину; настройки поверхностей и подвески выносить в ресурсы по необходимости. [План карьера](QUARRY_PLAN.md#1-отделить-машину-от-уровня).
- [ ] Создать локацию карьера с грунтовой дорогой, рельефом и окружением на основе общего запуска сессии, сохранив три испытания и отдельные рекорды трасс. [Этапы и критерии готовности](QUARRY_PLAN.md).

## P2 · Сетевой срез

- [ ] Запустить host/client с двумя машинами. Проверять владельца команд и запросов выстрела на сервере, передавать снимки для интерполяции на клиенте.
- [ ] Проверить двумя экземплярами управление каждой машиной, видимость движения и наведения, синхронизацию выстрелов и попаданий.
- [ ] После сетевого среза добавить реестр участников, серверный прогресс испытаний, результаты и PvP-урон.
