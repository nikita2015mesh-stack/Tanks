# Quarry_01 — планировка и маршруты (v0.1)

## Координаты и источник истины

**Машиночитаемый источник:** `quarry_01.json`. Генератор читает именно его. Схема `Quarry_01_layout.png` — визуализация, не замена координатам.

- Начало (0, 0) — юго-западный угол карты; север — направление +Z.
- Границы: 0 ≤ X, Z ≤ 1500 м. Центр карьера: (750, 750).
- Y в Unity — высота, `0..210 м` при импорте. Фактический верх карьера ~180 м.
- Террасы эллиптические, повернуты на 14°; контуры слегка неоднородны.
- Важные точные значения, включая координаты точек интереса в полярном виде, находятся в JSON.

## Схема движения

**M0 — основной серпантин**

- От низкого яруса (высота ~0) к верху (~180 м).
- Длина по плану ~4,8 км (по справочной генерации).
- Примерно 2,15 оборота вокруг карьера, достаточный радиус поворота.
- Проезжая часть 24 м, обочины по 11 м для сглаживания рельефа.
- Целевой продольный уклон: не более 12% на основном проезде.

**R1 — нижнее кольцо** (~45 м, 19 м проезжая часть).
**R2 — среднее кольцо** (~90 м, 22 м).
**R3 — верхнее кольцо** (~135 м, 23 м).
**R4 — внешнее кольцо** (~180 м, 28 м).

Радиусы по локальной эллиптической системе: 242, 342, 442, 542 м. Кольца стыкуются с серпантином. Генератор корректирует локальные высоты кольцевых дорог рядом с M0, чтобы не возникали резкие ступеньки на пересечениях. Не следует трактовать все четыре кольца как независимые идеально круглые трассы.

## Граф дорог для первого играбельного выпуска

```text
Старт A ─┐
         ├── R4 (верхнее кольцо) ── M0 ── R3 ── M0 ── R2 ── M0 ── R1 ── M0 ── Дно
Старт B ─┘
```

Здесь M0 — **одна непрерывная трасса**, а не несколько не связанных дорог. Кольца образуют обходные контуры. При первичном игровом тестировании подтвердить все реальные пересечения в 3D.

### Предлагаемые маршруты для версии 0.2 (ещё НЕ построены)

- S1: широкий отдельный спуск с внешнего кольца на R3 через западные уступы.
- S2: путь R3 → R2 с технической площадкой и разворотом в восточной части.
- S3: рискованный короткий спуск R2 → R1, угол и поверхность требуют испытаний подвески.
- T1: площадка для прыжка/среза (опционально, в зависимости от физики техники).

**Важная инженерная оговорка:** перечисленные S1, S2, S3, T1 пока описывают игровую цель. На иллюстрациях и в heightmap v0.1 этих дорог нет. Не выдавать их за готовые.

## Ключевые зоны

| ID из JSON | Игровая роль | Где | Задача |
|---|---|---|---|
| spawn_a / spawn_b | точки появления | противоположные участки R4 | тест сетевого боя, безопасный старт |
| north_overlook / south_overlook | огневые позиции | северный и южный края | дальние дуэли по противоположной стенке |
| crusher | ориентир и укрытие | верхний восток | промышленный силуэт |
| conveyor | средняя промышленная зона | запад, средний ярус | разрыв видимости и маршрутная цель |
| excavator | ориентир | дно карьера | крупный объект масштаба |
| floor_cover | ближние укрытия | дно, восток | ближний бой и уход из-под огня |
| west_boulders | группа валунов | западная стенка | засада / смена позиции |
| lower_mud | участок поверхности | нижний ярус | позже — изменение сцепления |

Детали и полярные координаты указаны в `quarry_01.json`, чтобы координаты можно было изменить без ручной правки множества файлов.

## Что измерить после импорта в Unity

1. Возможность непрерывно пройти M0 вверх и вниз, затем каждое R1–R4.
2. Способность реальной машины разворачиваться на серпантине без застревания.
3. Фактические продольные/поперечные уклоны, включая развязки.
4. Достаточность времени на разгон и торможение; число мест с невозможным обгоном.
5. Дальность и углы прострела между противоположными ярусами.
6. Существует ли обход противника без полного возврата к стартовой точке.
7. Логика выхода со стартовых площадок и защита от spawn camping.

## Отдельная оговорка о сетевой игре

Локальная сцена и дорожные меши/террейн не синхронизируются покадрово. Сетевая архитектура должна передавать состояния игроков и, позднее, детерминированные события изменений местности. Сначала тест: сервер + клиент на одной машине, второй клиент по LAN с другой машины. Не ставить отдельный выделенный компьютер обязательным условием игры.
