# Quarry_01 — Map Definition Pack v0.1

Рабочий пакет **небольшого генератора-референса + спецификации для Unity/Codex**. Основан на фотографиях реального многоярусного карьера. **Не является готовой Unity-сценой и не содержит готовых префабов техники/скал.**

## Четыре согласованных уровня входа

1. `01_CONCEPT.md` — концепт, атмосфера, виды и игровые ощущения.
2. `02_LAYOUT.md` + `Quarry_01_layout.png` + `quarry_01.json` — планировка дорог, зоны, координаты и масштаб.
3. `03_HEIGHTMAP.md` + `Quarry_01_heightmap_le.raw` — реальный рельеф (16-бит, для импорта в Unity).
4. `04_POPULATION.yaml` — укрытия, промзона, атмосфера и правила размещения.

**Дополнительно:** `05_GENERATOR_SPEC_FOR_CODEX.md` — конкретное ТЗ на первый этап интеграции в Tanks.

## Как воспроизвести генерацию на ПК

Требуется Python с пакетами `numpy`, `scipy`, `pillow`, `matplotlib`.

```bash
python generate_quarry_reference.py
```

Генератор прочитает `quarry_01.json` и пересоздаст графики, RAW и PNG. Для пересоздания после изменения архитектуры нужно изменять **JSON и сам генератор согласованно**: текущий скрипт v0.1 пока фиксирует часть геометрических формул.

## В Unity

Для первого импорта откройте [инструкцию для Unity](../README.md#quarry_01-в-unity) и выполните **Tools → Tanks → Maps → Generate Quarry_01**. Рельеф дорог берётся из `Quarry_01_heightmap_le.raw`. Схема `Quarry_01_layout.png` нужна для сравнения проездов и ориентации.

## Тесты/ограничения

`road_checks.json` содержит предварительные цифры уклона основных проездов с шагом измерения 10 м. Они не заменяют тестирование колёс/гусениц, реальной ширины полотна, физического сцепления, поперечных уклонов и игровых линий огня.

**У v0.1 нет отдельных альтернативных спусков S1–S3.** Внешние кольца дают манёвр, но полноценные переходы между ними, дополнительные маршруты, хорошие укрытия и асимметрия — ближайшие задачи v0.2 после испытания карьера.

## Новое основное ТЗ (v0.2)

Система генерации описана в `Docs/Maps/MAP_GENERATOR_SPEC.md` (на две папки выше). Файл `05_GENERATOR_SPEC_FOR_CODEX.md` в этой папке сохранён как историческая спецификация первого прототипа; в случае расхождений приоритет у `MAP_GENERATOR_SPEC.md`.

Для быстрой проверки исходных данных без сторонних библиотек: `python validate_sources.py`.
