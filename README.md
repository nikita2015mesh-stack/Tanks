# Mad Machines

«Безумные машины» — локальная альфа соревновательной физической аркады. Проект использует **Unity 6000.6.8f1** (Unity 6.6), URP и Unity Input System.

## Запуск

Используемые модели, материалы, текстуры, подготовленные колёса и их `.meta` хранятся в Git. После клонирования проекта отдельно импортировать T100 через My Assets или запускать Blender не требуется. Unity восстановит пакеты из `Packages/manifest.json` и `Packages/packages-lock.json`.

1. Открой корень репозитория в Unity 6000.6.8f1 и дождись импорта.
2. Открой [FrontEnd.unity](Assets/MadMachines/Scenes/FrontEnd.unity) и нажми Play. С главного можно войти в сетевую игру. Для настройки машины и пробного заезда открой «Гараж».
3. В гараже выбери локацию и нажми «Выехать». Если настройки изменены, «Применить и выехать» сохранит их перед запуском. Из паузы вернись в гараж.

**Сборка Windows** — **Tools → Mad Machines → Build Windows player**. Команда собирает игру с меню, гаражом, полигонами и картой «Три дороги» в `Builds/MadMachines/MadMachines.exe`.

**Сборка Linux** — **Tools → Mad Machines → Build Linux player**. Запускаемый файл — `Builds/MadMachines-Linux/MadMachines.x86_64`. [Запуск вдвоём по LAN](Docs/NETWORKING.md#два-компьютера-в-lan-на-mx-linux).

Пробные заезды проходят в свободной езде без сервера. Локации также открываются напрямую в Unity.

- [Полигон — асфальтовая трасса](Assets/MadMachines/Scenes/Location_AsphaltTrack.unity) · [Сценарий проверки](Docs/CURRENT_STATE.md#испытательная-трасса)
- [Полигон — грунтовая трасса](Assets/MadMachines/Scenes/Location_DirtTrack.unity) · [Сценарий проверки](Docs/CURRENT_STATE.md#грунтовый-полигон)
- [Стрельбище](Assets/MadMachines/Scenes/Location_ShootingRange.unity) · [Маршрут и проверка](Docs/CURRENT_STATE.md#стрельбище)

**Игра по сети** — в **Tools → Mad Machines → Networking** выбери «Собрать сервер для Windows» или «Собрать сервер для Linux». Клиент подключается в фоне. На главном дождись зелёного индикатора и нажми «В бой». Для старта «Трёх дорог» нужны две заявки. Сервер использует UDP 7777 и 7778. [Запуск на Windows](Docs/NETWORKING.md#сервер-на-windows-11) · [Запуск на MX Linux](Docs/NETWORKING.md#два-компьютера-в-lan-на-mx-linux).

## Структура проекта

Корень репозитория — Unity-проект Mad Machines. `Assets/MadMachines/` содержит код, сцену и ресурсы игры; `Assets/ASEED/` и `Assets/_ThirdPartyLocal/` — стороннюю модель T100 и подготовленные колёса. `Assets/Settings/`, Input System и пакеты содержат общие настройки и зависимости.

Прежний прототип Т-34 хранится в [Archive/T3485](Archive/T3485/README.md) вне `Assets`, вместе со сценой, скриптами и `.meta`. Инструкция архива описывает восстановление в отдельной копии проекта. Первая сцена в настройках сборки — FrontEnd; название продукта — `Mad Machines`.

## Управление

- **WASD** — газ, задний ход и поворот. В одиночной игре нажатие противоположного направления сначала тормозит, а удержание той же клавиши после остановки продолжает движение в выбранную сторону. **Пробел** — ручной тормоз для заноса.
- **Мышь** — обзор и наведение, **ЛКМ** — огонь. **1 / 2 / 3** — пулемёт, баллистическая пушка и гранатомёт. **B** — смена боеприпаса пушки в одиночной игре.
- **4** — ПТУР на стрельбище. После пуска ведите ракету мышью по прицелу.
- **5** — НУРСы на стрельбище. Два одиночных пуска, затем 15 секунд перезарядки.
- **C** — переключение между видом от третьего лица и прицельным видом.
- **R** — восстановление машины. **Esc** — пауза и освобождение курсора.
- **P** — стояночный тормоз в одиночной игре. На стрельбище машина также удерживается автоматически после остановки. **W** и **S** отпускают удержание.
- На стрельбище **колесо мыши** меняет установку дальности в оптике. **Shift + колесо** даёт шаг 5 м. **H** включает прогноз попадания, **F** восстанавливает мишени. Наведи перекрестие на плиту и нажми **T** для смены толщины или **Y** для изменения наклона.
