# MAD MACHINES: Physics Playground

Рабочая локальная альфа на Unity **6000.6.8f1** (Unity 6.6), Windows, URP и Unity Input System. Новая сцена и ресурсы находятся в `Assets/MadMachines/`; прежний прототип Т-34-85 сохранён отдельно.

## Быстрый запуск

1. Открой `C:/Projects/Tanks` в Unity 6000.6.8f1 и дождись импорта.
2. Открой `Assets/MadMachines/Scenes/Playground.unity` и нажми Play.
3. Выбери FREE DRIVE, RACE, TARGET RUSH или COMBAT COURSE.

Если сцены ещё нет: **Tools → Mad Machines → Create or open playground**. Команда создаёт сцену только при отсутствии файла, иначе открывает существующую. Для сборки: **Tools → Mad Machines → Build Windows player**; результат — `Builds/MadMachines/MadMachines.exe`. Сборка использует только новую сцену и не меняет список сцен старого проекта.

## Управление и правила

- WASD — газ, торможение/задний ход, поворот; Space — ручной тормоз и занос.
- Мышь — камера и наведение; ЛКМ — огонь; 1/2/3 — пулемёт, баллистическая пушка, тяжёлая граната.
- R — восстановить машину; в гонке и боевой трассе возврат к последним воротам стоит 3 секунды.
- Esc — пауза и освобождение курсора; из меню паузы доступны повтор и возврат в гараж.

Белый прицел показывает направление оружия, жёлтый круг — прогноз первого контакта снаряда с миром. У гранаты есть отскоки и взрыв через 3,2 секунды. Полоса снизу показывает перезарядку. Движущиеся красные цели дают 200 очков, неподвижные — 100.

**Гонка:** после отсчёта пройти восемь ворот по порядку; следующие подсвечены зелёным. Лучшее время меньше. **Стрелковый полигон:** уничтожать цели за 60 секунд; можно перемещаться, результат — очки, больше лучше. Уничтожение всех целей завершает попытку досрочно. **Боевая трасса:** те же ворота плюс цели; результат = время + 8 секунд за каждую оставшуюся цель + 0,25 секунды за каждый выстрел без попадания. Меньше лучше.

После финиша показаны результат, локальный топ-5 и повтор. Рекорды хранятся в PlayerPrefs отдельно для каждого режима. Новая попытка восстанавливает цели, машину, таймер и перезарядку. Разбросанные физические предметы пока сохраняют своё положение до перезапуска сцены.

## Проверка

Автоматический Play Mode прогон в установленном Unity 6000.6.8f1 прошёл 20 проверок: подвеска, разгон, поворот, восстановление, физическое попадание пушкой, ограничения стрельбы, три оружия, таймер гранаты, отсчёт, порядок ворот и реальные триггеры финиша, результаты трёх режимов, таймаут и повтор. Проверки игровых правил дополняют физический выстрел: все цели в тесте начисления очков поражаются прямым вызовом, полный заезд человеком они не заменяют. Рекорды пользователя тест не изменяет.

Повторить при закрытом редакторе (PowerShell):

```powershell
& 'C:/Program Files/Unity/Hub/Editor/6000.6.8f1/Editor/Unity.exe' -batchmode -nographics -projectPath C:/Projects/Tanks -executeMethod MadMachines.Editor.PlaygroundEditor.BuildAndVerify -logFile C:/Projects/Tanks/Logs/MadMachines-unity.log
```

Итог: `Logs/MadMachines-verification.txt`. Не добавляй `-quit`: проверка сама завершает редактор после Play Mode.

Ручная проверка пользователем ещё нужна: изображение и читаемость HUD, мышь и прицел, заносы/трамплины, удобство полного маршрута, звук (пока отсутствует), сохранение топ-5 после перезапуска. Автоматизация интерфейса остановлена по просьбе пользователя.

Новая сцена пока однопользовательская. Есть разделение ввода, физики, оружия, правил и HUD; сетевую синхронизацию ещё предстоит реализовать. Подробности: [ARCHITECTURE.md](ARCHITECTURE.md), [ROADMAP.md](ROADMAP.md).

## Сохранённые заметки предыдущего прототипа

# Tanks

Прототип танковой игры на Unity с моделью Т-34-85. Для запуска нужен отдельный Unity-проект.

## Текущее состояние

Первый танк прототипа — Т-34-85. По ручной проверке Никиты в Unity при запуске видна открытая тестовая площадка с танком, а слева — панель ангара с кнопкой **В БОЙ**. После нажатия танк ездит по небольшой платформе с видимыми краями. При горизонтальном повороте камеры башня следует за ней.

Никита проверил выстрел, круг сведения и визуальную обратную связь после выстрела. В исходнике повторный выстрел ограничен таймером, а круг расширяется после выстрела и затем сужается. Отдельного индикатора времени перезарядки в коде нет.

- `BuildT3485.cs` генерирует геометрию, материалы и префаб Т-34-85 в редакторе Unity.
- `T3485-Unity.unitypackage` содержит генератор для импорта в `Assets/Editor/`.
- `TankPrototypeControls.cs` отвечает за движение, наведение башни, выстрелы, камеру и интерфейс ангара и боя.

## Запуск и проверка в Unity

1. Импортируй `T3485-Unity.unitypackage` или скопируй `BuildT3485.cs` в `Assets/Editor/`. Проверь консоль Unity после компиляции.
2. Открой тестовую сцену и выбери **Tools → T-34-85 → Build model in scene**. Генератор сохраняет сцену и создаёт `Assets/T-34-85/T-34-85.prefab`. Для проверки генерации используй проект без этого префаба. Если префаб уже есть, команда выбирает его. Проверь консоль после генерации.
3. Включи Unity Input System. Скопируй `TankPrototypeControls.cs` в `Assets/` вне папки `Editor`, добавь компонент на корневой объект танка и назначь башню и камеру в Inspector. Для выстрелов объект `Gun Barrel` должен быть непосредственным дочерним объектом башни.
4. В Play Mode нажми **В БОЙ** и проверь движение на WASD, наведение мышью и Q/E, выстрел левой кнопкой мыши и освобождение курсора по Escape.

Автоматических тестов в репозитории пока нет.
