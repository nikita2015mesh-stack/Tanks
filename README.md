# Mad Machines

«Безумные машины» — локальная альфа соревновательной физической аркады. Проект использует **Unity 6000.6.8f1** (Unity 6.6), URP и Unity Input System.

## Запуск

Используемые модели, материалы, текстуры, подготовленные колёса и их `.meta` хранятся в Git. После клонирования проекта отдельно импортировать T100 через My Assets или запускать Blender не требуется. Unity восстановит пакеты из `Packages/manifest.json` и `Packages/packages-lock.json`.

1. Открой корень репозитория в Unity 6000.6.8f1 и дождись импорта.
2. Открой [Playground.unity](Assets/MadMachines/Scenes/Playground.unity), нажми Play и выбери режим в гараже.
3. Если файла сцены нет, используй **Tools → Mad Machines → Create or open playground**.

**Сборка Windows** — **Tools → Mad Machines → Build Windows player**. Команда собирает Playground в `Builds/MadMachines/MadMachines.exe`.

## Структура проекта

Корень репозитория — Unity-проект Mad Machines. `Assets/MadMachines/` содержит код, сцену и ресурсы игры; `Assets/ASEED/` и `Assets/_ThirdPartyLocal/` — стороннюю модель T100 и подготовленные колёса. `Assets/Settings/`, Input System и пакеты содержат общие настройки и зависимости.

Прежний прототип Т-34 хранится в [Archive/T3485](Archive/T3485/README.md) вне `Assets`, вместе со сценой, скриптами и `.meta`. Инструкция архива описывает восстановление в отдельной копии проекта. Основная сцена в настройках сборки — Playground; название продукта — `Mad Machines`.

## Перенос прежних рекордов

До переименования название продукта в Unity было «Танчики». Ключи рекордов `MadMachines.Records.v1.*` сохранены, но хранилище PlayerPrefs зависит от названия продукта. Старые данные остаются на компьютере в прежнем хранилище; автоматически они не переносятся.

Если нужно сохранить прежний топ-5, закрой Unity и игру, сделай резервные копии обоих хранилищ и перенеси старые записи до новых заездов:

- **Linux:** скопируй файл `~/.config/unity3d/DefaultCompany/Танчики/prefs` в `~/.config/unity3d/DefaultCompany/Mad Machines/prefs`, создав папку назначения. Это заменит всё содержимое нового хранилища.
- **Windows:** в редакторе реестра экспортируй старую ветку PlayerPrefs и импортируй её копию с заменой названия продукта в пути на `Mad Machines`. Для редактора Unity ветка находится в `HKEY_CURRENT_USER\Software\Unity\UnityEditor\DefaultCompany\Танчики`, для отдельной игры — в `HKEY_CURRENT_USER\Software\DefaultCompany\Танчики`. Переноси значения `MadMachines.Records.v1.*` вместе с добавленными Unity суффиксами в одноимённую новую ветку; редактор и сборка используют отдельные хранилища.

После переноса открой гараж и проверь топ-5 всех трёх испытаний и его сохранение после перезапуска. Сохрани резервные копии до завершения проверки. На других платформах перенос хранилища требует отдельной инструкции.

## Управление

- **WASD** — газ, торможение/задний ход и поворот. **Пробел** — ручной тормоз.
- **Мышь** — обзор и наведение, **ЛКМ** — огонь. **1 / 2 / 3** — пулемёт, баллистическая пушка, тяжёлая граната.
- **C** — переключение между видом от третьего лица и прицельным видом.
- **R** — восстановление машины. **Esc** — пауза и освобождение курсора.
