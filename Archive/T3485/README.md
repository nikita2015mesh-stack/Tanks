# Архив прототипа Т-34-85

Здесь сохранены прежняя танковая сцена, её контроллер с сетевой панелью, материал и исходные `.meta`. В корне архива находятся генератор `BuildT3485.cs`, его `T3485-Unity.unitypackage` и отдельная локальная версия `TankPrototypeControls.cs`. Содержимое перенесённых файлов и GUID не менялось.

Архив находится вне `Assets`: Unity текущей игры не импортирует эти ресурсы и не компилирует старые скрипты. Это комплект для восстановления прототипа на базе копии текущего проекта, а не самостоятельный Unity-проект.

## Как восстановить

1. Создай отдельную копию текущего проекта без `Library`, `Temp`, `Logs` и `UserSettings`. Сохрани в ней `Packages`, `ProjectSettings` и текущие `Assets`: они содержат общие зависимости сцены.
2. При закрытом Unity скопируй содержимое `Archive/T3485/Assets/` в `Assets/` этой копии вместе со всеми `.meta`.
3. Открой копию в Unity версии из `ProjectSettings/ProjectVersion.txt`, дождись импорта и открой `Assets/Scenes/SampleScene.unity`.
4. Для сборки прототипа замени Playground на SampleScene в списке сцен Build Profiles. Запускай обычную сборку Unity: команда **Tools → Mad Machines → Build Windows player** всегда выбирает Playground.
5. Проверь консоль, переходы заставка → ангар → бой, управление, наведение, стрельбу и подключение двух экземпляров по [исторической инструкции](../../Docs/archive/T3485.md).

`Assets/Settings/SampleSceneProfile.asset` оставлен в текущем проекте: на него ссылаются оба профиля URP и демонстрационная сцена ASEED. Input System, URP, ProBuilder, Netcode и его автоматически создаваемый `Assets/DefaultNetworkPrefabs.asset` также остаются общими зависимостями. При восстановлении в копии проекта эти ссылки сохраняются.

Корневой `TankPrototypeControls.cs` — другая, локальная версия контроллера. Не копируй её одновременно с `Assets/TankPrototypeControls.cs`: имена классов совпадают. Для открытия сохранённой SampleScene используй версию из архивного `Assets` с её `.meta`.

Для новой генерации модели импортируй архивный `T3485-Unity.unitypackage` либо скопируй `BuildT3485.cs` в `Assets/Editor/` отдельной копии проекта. Перенос в архив не менял генератор и его пакет.

После переноса тесты, сборка и Play Mode агентом не запускались. Работоспособность восстановленного прототипа должен проверить пользователь.
